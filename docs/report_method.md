# 方案分析报告：论文依据、系统架构与方法演进

> 更新：2026-10-21 ｜ 姊妹篇：[report_experiments.md](report_experiments.md)（实验结果）｜ 逐版细节：[CHANGELOG.md](CHANGELOG.md)

## 1. 任务与系统架构

任务：网络质量保障客服的多轮多意图 DST。一轮用户话语可含多个保障意图/修改/取消/画像指代，系统维护累积对话状态（7 字段：application_name / service_name / resolution / rtt / start_timestamp / end_timestamp / duration）。

```
user utterance + prev_state
    │  Embedding(prev_state || utterance)
    ▼  DiverseRetriever (MMR, top_k=3)          ← RefPyDST (B1)
    ▼  prompt = schema + 规则 + 画像 + demos     ← IDIC-DST (B2) 画像增强 / v11 选择链 / v12 纠正 demo
    ▼  LLM 生成 Text-to-Python 程序（v14.0 起 qwen-plus；v13 及以前 Qwen3-32B）
       （每 intent 段强制 # summary PAR）         ← S3-DST PAR
       （可选上下文段：AGENT LAST REPLY ← v13.1 agent_context）
    ▼  execute_program_multi 受限沙箱 → Δy       ← RefPyDST (B1)
    ▼  PAR/取消校验回路（缺 summary/缺 # cancel 重采样1次）
    ▼  Rule Validator: apply Δy→y_t + schema 矩阵 + 时间知二推一
    ▼  final_state（真实透传到下一轮）
```

## 2. 论文依据与采纳判断

论文库：`D:/l00929784/连接Agent/网络保障客服_论文/`（A–E 五类 25 篇，均有详读笔记）；S3-DST PDF 在 `paper/S3-DST.pdf`。

改口/否定处理的论文调研结论（2026-08-19）：库内无论文以"用户改口检测"为核心机制；MoNET (Zhang 2022) / TripPy (Heck 2020) 是库外指针（需训练）。最终采用"纠正类 demo + demo 格式对齐"（v12.1，无需训练）解决。

改口场景的评估口径补丁（2026-08-28，v20.2）：错误值轮（T2-3 轮1/T3-2 轮2）GT 记字面错误值属设计口径（不动数据），评估侧加 `correction_credit`——模型拒收（pred 空）或记字面值均计命中，其余字段照常比对；与 v17.1 取消计分同构，默认开，`--no_correction_credit` 回退。v20.0 复算 turn +2.04pp（14 转正/7 仍错，仍错全为真实错误）。

turn 级 GT 知二推一口径补丁（2026-09-03，v25.1）：GT 标注只在"字面明说"轮登记字段，而模型侧 validator 每轮强制知二推一且 GT 最终态三字段必齐——turn 级中间态 29 处（test 11，全 X-2 duration）"GT 未推算 vs 模型已推算"假错误。评估侧加 `gt_derive`（turn GT 比对前与 validator 同规则补齐，只补缺失不覆盖），默认开，`--no_gt_derive` 回退。v24.1 双跑复算 turn +1.61pp/+1.61pp（+11/−0），session 级不变。反向"关模型推导"证伪不可行：判对 turn 的 83/502 靠 validator 推导。

harness 侧意图对象语义修复（2026-09-04，v25.2，当前最佳）：增量 Text-to-Python 范式里模型自造的 `# intent: app/svc` 字符串头是意图的唯一"引用通道"，身份与内容耦合导致三类 key 断裂（改口单字段裂 key / 补槽轮 prev 匹配不到致 stub 并存 / 改名后旧 key 残留幻影）。修复=在 harness 模拟对象语义：key 从合并后 final_state 导出（状态=prev+delta 合并，规范名从当前内容导出）+ 无 app 归并链 + consumed key 退役；prompt/协议零改动。**+6.52pp/+3.35pp（双跑均值 87.27%/88.47%），项目最大单步收益**。方法论教训：模型行为异常先查 harness 结构（引用解析/状态合并/生命周期），再归因模型能力——v24.1 时代 missed_intent 的"能力短板"实为 key 断裂假象。

v26.0→v26.2b id 协议补丁链（2026-09-07~08，最终采纳）：裸 id 协议双跑净负 −3.11pp（补全型共指模型承担不了、cancel id 错位、遵从≠语义正确）→ 三轮"翻转归因→补丁"迭代：①new 段归并校验（无 app 同 svc 互补→prev 填空槽+残骸退役，两级信号）②cancel 强制写名字（名字自校验；id 分配序与模型心智模型错位无法从格式识别）③身份判定强制化（段头前强制 `# 身份判定:` 行，PAR 式生成前推理+demo 逐字节一致+PAR 校验重采样）④full-match new 重采样门⑤段去重（同轮 I1 段与冗余 new 段产出同 key 时先到先得）。**v26.2b 双跑 88.67%/88.83%，对 v25.2 +1.39pp/+0.37pp，方差更小（0.31pp 极差），采纳为当前最佳**。最终结论——引用解析的责任分配是三层混合：模型显式指派（id/名字）+ harness 推断兜底（归并/重采样门）+ 全场去重审查；身份判定的收益在"强制写出生成前理由"而非"换引用介质"（与 v11 选 record PAR 同构）。**实验卫生教训：含 bug 的采样（v26.2 段覆盖）必须从统计中剔除，否则多数票/均值全部失真**。

v27.0 时间锚点与明说时间证据注入（2026-09-20）：时间类错误在 d6 最佳配置上居首（run5 time_wrong 19/50 turn，session 败 13/28 涉时间），跨 5 跑核查 11 个 session 属机制性。**形态决策（两条直觉路线均有否决证据）：后处理提取纠错 = v23/v9.0 已封死（对已规范输出恒等、二次干预连带破坏，且本批 GT 口径反规范化——矛盾保字面、OCR 保字面）；LLM 时间改写轮 = 改写器与 DST 共享同一日期算术弱点，误差上移且每轮多一次调用**。采纳路线 = **规则提取器 + 预解析 + 触发型 prompt 注入**（规则负责算、模型负责理解与绑定，与 v24.1 record_rule 以来全部成功改动同构）。论文支持（arXiv 检索 2026-09-20）：**arXiv:2505.16088**（Date Fragments）证明日期错误部分源于 BPE 分词割裂、不常见日期掉点达 10pp——prompt 文字规则教"明天=ref+1"救不了符号重组，须给预计算结果；**arXiv:2601.07148**（Time Puzzles）GPT-5 无工具 55.3%、**显式给日期时性能显著提升**——直接支持 TIME ANCHOR 预计算日期表；**arXiv:2511.09993**（SPAN 跨历法）LLM 平均 34.5%、工具增强代码生成 agent 95.31%——时间计算应交确定性代码（本项目 find_timestamp 沙箱同构，错误在参数生成端）；**arXiv:2507.06450** 时间归一化 = LLM 代码生成+可执行校验框架；**arXiv:2505.20243**（It's High Time, ACL 2026 综述）时间表达式归一化在窄域仍以规则系统（SUTime/HeidelTime/Duckling）为基线强度。实现六开关独立消融：time_anchor（日期表+散文段压缩，系统 prompt 净 −840 字符对冲变长）/time_extractor（TIME EVIDENCE）/time_rule_{contradiction,profile_slot,explicit_first,candidate}（矛盾保字面/画像时段优先/明说>record/候选不落槽）；提取器 d6 全量扫描组装值与 GT 一致 314/316=99.4%（仅 2 例不一致全是 GT 侧噪声字面"3G分"/"19点70分"）。离线回放 11 目标+12 对照：修 7 破 0（两轮迭代后）。**全量采纳定案（fix3）：session 92.74%/turn 93.54%/状态机 86.08%，vs v26.3-p3 +4.71pp/+3.64pp**（±2pp 噪声带 2 倍+，用户拍板单跑差距大免双跑），time_wrong 19→5，11 目标 case 8 转正，回退 6 个经基线五跑稳定性核查确认无机制性回退。中途 run1 −6.8pp 大回退→区间终点省略时段词根因修复（子句级时段继承/跨夜滚动），回放纪律补丁：对照组须盯 turn 级 time_wrong 增量。方案与错误归类全文 `docs/plan_time_anchor_20260920.md`。
