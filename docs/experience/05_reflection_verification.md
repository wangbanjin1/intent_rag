# 05 反思/校验回路：为什么全线失败，以及什么条件下值得做

> 来源：v25.0（窄版冲突检查 −1.86pp/−0.80pp 双跑回退）、v24.5（oracle pass@2 +1.63pp 门控）、report_reflection.md 全链（Reflexion/Self-Refine/CRITIC/Self-Debugging 调研 + 三次同构证伪）

## 1. 三次同构证伪（本项目的定论）

| 尝试 | 形态 | 结果 |
|---|---|---|
| §6 代码核验 | 反思回路方案设计 | invalid≠错误（Collecting 中间轮是常态）、执行错误被沙箱吞、时间错多为"自洽但推错" |
| v23.2 | 时间规则离线回放 | 真靶区 2 turn，+0.62pp < 噪声带 |
| v25.0 | 窄版冲突检查反思回路（bounded 1 轮、逐意图采纳、0 误报） | 双跑一致净负；触发 10/采纳 1（采纳例还是选择疑问句陷阱）；9/10 模型拒绝改动 |

**结论：校验信号驱动的反思/自纠，在本数据集上靶区结构性太小（上限 +0.6pp < ±1.5pp 噪声带），采样侧 oracle pass@2 仅 +1.63pp 同样封死。任何"让模型再看一遍"的机制，预期收益都低于 API 噪声。**

## 2. 为什么没有靶区（可迁移的根因分析）

1. **invalid ≠ 错误**：validator 的 invalid 大部分是"正常未收齐"（Collecting 中间轮），不是真错误——把校验信号当错误信号，第一层就是错的。需要信号分层（hard=time 矛盾/矩阵越界；soft=缺槽不报）。
2. **执行错误被沙箱吞**：程序执行失败 delta 为空，校验器看不到"错"只看到"无"。
3. **时间错是"自洽但推错"**：推算链内部一致（end-start=duration），字面比对无矛盾可抓。
4. **"话语明说值 vs 输出值"比对被表达方式污染**：选择疑问句（"20ms 还是按上次记录"——20ms 是被选项）、上下界表述（"不超过50ms"≠rtt=50ms）、多意图串扰（值-意图绑定歧义）、改口轮新旧值同在。检测器逐项收窄后（近邻绑定/跳过规则/中文数词归一）误报 83%→0，但真靶区也只剩 4 turn。
5. **模型对"校验器说你错"以拒绝为主**（9/10）：置信冲突的实证——模型对自己的输出先验很强，反思提示不足以翻转，反而引入扰动。

## 3. 什么条件下反思/校验回路值得做（迁移判据）

1. **存在可计算的、低误报的错误信号**：本项目最终只有"话语明说值 vs 输出值"这一类，且被表达方式污染。若你的任务有强结构校验（SQL 可执行性、代码编译/测试、数学验算），靶区会大得多——CRITIC 在代码/数学任务有效正是此因。
2. **错误是"发散型"而非"自洽型"**：模型输出在正确答案附近随机散布 → 重采样/投票有收益；错误是自洽的推错链 → 再看一万遍也是错的。
3. **先跑 oracle 门控**：模拟完美反思器（把已知错误全部修正）能涨多少。低于噪声带 × 1.5 → 直接关闭路线（本项目的 3pp 门槛）。
4. **反思提示的采纳率要实测**：触发→采纳转化率低于 20% 的机制，扰动大于收益。

## 4. 采样的定量封死（可复用的公式）

翻转 turn 即 p≈0.5 的边缘 turn。N 选一多数投票命中 f(p)=3p²−2p³，净增益 f(p)−p：p=0.5→0，p=0.6→+0.048，p=0.7→+0.084。50 个边缘 turn 期望 **0~0.6pp，需 3~5× 推理成本**。投票要兑现收益的前提是错误"发散"，而字段级投票还会破坏字段耦合（时间三字段、key↔app/svc）——v9.0 选择器失败的结构性重演。

**唯一能突破的形态**：Best-of-N + 独立训练的 verifier（判别模型，历史 eval 可作训练数据）——这是新训练投入，不是 prompt 技巧，需单独立项决策。

## 5. 本项目的替代去向

反思路线关闭后，同样的投入转到生成侧（v24.1 records[0] 规则 +4.97pp、v26.2b 补丁链 +1.39pp）——**给模型看信息，比让模型自查，性价比高一个量级**。校验器并没有白做：signal_level/detect_utterance_conflicts 最终用在了 err_report 归因（v20.1 二级标签）和身份判定 PAR 校验上——**同一套校验信号，用于"生成前决策"有效，用于"生成后纠错"无效**。
